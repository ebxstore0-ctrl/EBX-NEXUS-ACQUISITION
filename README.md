# EBX Nexus — Acquisition Presentation

Professional bilingual (Arabic / English) acquisition presentation for EBX Nexus.

## Stack
- React 19
- TypeScript
- Vite

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Repository
This repository contains the presentation source code and assets required to run the presentation locally.
